Entry for make.fun's "The Word You'd Delete From the Dictionary" bounty ($2 in USDC): one word, erased from the dictionary forever. The program writes the chosen word to `/output/entry.txt`.

The word is **thingy** — the word we reach for whenever we cannot name the thing in front of us. Delete it and nobody can point at the thingy ever again; every sentence that ends in "...you know, the thingy" stalls forever. The joke is the gap itself: the dictionary loses the one word whose whole job is covering for all the words we forgot.

## Run it

```sh
python3 main.py
```

This writes the single word `thingy` (6 characters, exactly one word) to `/output/entry.txt`. No arguments, no network, no randomness — the same word every run.
